# Кейс 8. Работа амбассадора

<details>
  <summary><h3>📖 Условие кейса</h3></summary>

  Крупные IT-компании часто ведут активную деятельность в медиа-простраснстве для создания положительного имиджа работодателе. Одним из таких способов является отбор амбассадоров (люди, продвигающие бренд) среди школьников старших классов и студентов. Например, программа U-Team компании Яндекс, которая проводит отбор и подготовку амбассадоров среди студентов вузов.

</details>

<details open> 
  <summary><h3>❗ Задание</h3></summary>
  
  1. Разбиться в группы по два человека
  2. Условие: _1 февраля стартует летняя стажировка в Яндексе. Твоя задача, как амбассадора, рассказать об этой программе в своём университете так, чтобы охватить как можно больше целевой аудитории._
  3. Подготовить и оформить пост-приглашение (картинка + текст) на стажировку в Яндекс для студентов твоего университета и/или твоих подписчиков в соцсетях.
  4. Собрать презентацию для выступления внутри вуза. Главная цель выступления — рассказать о стажировках, чтобы о них узнали и заинтересовались даже те, кто о стажировках прежде не слышал (первокурсники, преподаватели, внешние гости).
  3. В форме укажите, какие каналы можно использовать для продвижения вашего поста о стажировках в своём университете? Укажите три лучших канала. Изучите, что сейчас делает Яндекс для студентов и предложить форматы/ивенты/проекты, которых, на ваш взгляд, сейчас не хватает, чтобы ещё эффективнее привлекать студентов к стажировкам.
  5. [Для сдачи работы заполните в форму]()
  
  **Рекомендации**
  Используйте для оформления презентации инструменты: MS PowerPoint, Keynote, Figma, Canvas и другие.
  Презентация по времени не должна быть более 5-7 минут. Не делайте большое количество слайдов - 4
  достаточно.


</details>
